# Task 8: Draw The Player

## Goal

Make the player visible.

## Key Words

| Word | Meaning |
| --- | --- |
| Polygon2D | A node that draws a custom 2D shape. |
| Point | One corner of a polygon shape. |

## Do This

1. Open `scenes/Player.tscn`.
2. Right-click `Player`.
3. Add a `Polygon2D`.
4. Make a triangle using these points:

```text
(0, -20)
(16, 16)
(-16, 16)
```

5. Set the colour to a bright arcade colour.

![Player checkpoint](../assets/images/task-02-player.png){ .media-frame }

## Check

The player should look like a small triangle ship.
