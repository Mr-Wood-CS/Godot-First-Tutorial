# Task 6: Set The Main Scene

## Goal

Tell Godot which scene should open first.

## Key Words

| Word | Meaning |
| --- | --- |
| Main scene | The scene Godot opens when the game starts. |
| Play button | The button that runs the game. |

## Do This

1. Press **Play**.
2. If Godot asks for a main scene, choose **Select Current**.
3. If it does not ask, open **Project > Project Settings > Application > Run**.
4. Set **Main Scene** to `res://scenes/Main.tscn`.

## Check

Pressing Play should open a game window showing the `NEON DRIFT` title.
