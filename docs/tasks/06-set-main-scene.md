# Task 6: Set The Main Scene

## Goal

Tell Godot which scene should open first.

## Do This

1. Press **F6** and check the current scene still opens, then close the game window.
2. Press **F5** to run the whole project.
3. When Godot says no main scene has been defined, click **Select Current**. This tells Godot to start with the scene that is open now: `Main.tscn`.

## Check

Pressing **F5** should now open a game window showing the `NEON DRIFT` title without asking you to choose a scene.
