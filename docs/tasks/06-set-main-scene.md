# Task 6: Set The Main Scene

Choose the scene that opens when you run the game.

## 1. Find the scene file

1. Stop any running game with **F8**.

2. In the **FileSystem panel at the bottom left**, open the ==scenes== folder.

3. Double-click ==Main.tscn== to open it, then choose **Scene > Save Scene**.

## 2. Set the starting scene

In the FileSystem panel, ==right-click== the file ==Main.tscn== and choose **Set As Main Scene**.

Use the file in the FileSystem panel for this step. You can repeat it if you picked the wrong scene earlier.

## 3. Check

Press **F5**. The game should open with the NEON DRIFT title without asking you to choose a scene.

| Key | What it runs |
| --- | --- |
| F5 | The whole game, starting with Main |
| F6 | Only the scene you have open |

Use **F5** to test the whole game in the tasks that follow. Close the game window when finished.
