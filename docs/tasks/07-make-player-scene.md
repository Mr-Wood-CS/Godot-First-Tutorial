# Task 7: Make The Player Scene

Create the player ship scene.

## Watch First

<iframe width="100%" height="360" src="https://www.youtube.com/embed/CQ36QANa44M" title="YouTube video: Godot 4 top-down movement" allowfullscreen></iframe>

## 1. Create the scene

1. Choose **Scene > New Scene** from the top menu. Save your work if asked.

2. In the **Scene panel at the top left**, click **Other Node**.

    ![Scene panel with the Other Node button at the bottom](../assets/images/scene-panel.png)

3. Search for ==CharacterBody2D==, select it, and click **Create**.

## 2. Name the node

==Right-click== the new ==CharacterBody2D== in the Scene panel and choose **Rename**.

![Scene panel menu with Rename circled](../assets/images/rename.png)

*The screenshot shows Node2D. Rename your CharacterBody2D node instead.*

Type ==Player== and press Enter.

## 3. Save and check

1. Choose **Scene > Save Scene** from the top menu.

2. In the save window, open the ==scenes== folder.

3. Enter ==Player.tscn== in the **File** box and click **Save**.

The Scene panel should contain one node named ==Player==. The FileSystem panel should show ==Player.tscn== inside ==scenes==.
