# Task 7: Make The Player Scene

## Goal

Create a separate scene for the player ship.

## Watch First

<iframe width="100%" height="360" src="https://www.youtube.com/embed/CQ36QANa44M" title="YouTube video: Godot 4 top-down movement" allowfullscreen></iframe>

## Key Words

| Word | Meaning |
| --- | --- |
| Player | The object controlled by the person playing. |
| CharacterBody2D | A Godot node made for moving 2D characters. |

## Do This

1. Create a new scene.
2. Choose **Other Node**.
3. Search for `CharacterBody2D`.
4. Rename it to `Player`.
5. Save it as `scenes/Player.tscn`.

## Check

You should have a scene called `Player.tscn` with a root node called `Player`.
