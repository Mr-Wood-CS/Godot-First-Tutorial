# :material-map: Lesson 20 - Level Design and Extension

Source videos: Whole playlist review

## Learning Intention

Extend the basic game by improving the level layout and adding a small extra feature.

## Success Criteria

- I can arrange Sparks with intention.
- I can balance challenge and fairness.
- I can add one extension feature.
- I can explain my design choices.

## Keywords

| Keyword | Meaning |
|---|---|
| Level design | Planning the space and challenges in a game. |
| Difficulty | How challenging the game is. |
| Extension | An added feature beyond the basic tutorial. |
| Balance | Making challenge feel fair. |


## Extension Ideas

Choose one extension only after the core game passes the Lesson 18 checklist:

1. **Supported:** Add more Sparks and update `target_score` to match their total value.
2. **Supported:** Rearrange Sparks and ask a classmate to test whether every Spark is reachable.
3. **Intermediate:** Add a hazard that reloads the current scene when the Player touches it.
4. **Intermediate:** Add a sound effect when a Spark is collected.
5. **Advanced:** Add a timer or a second level.

Save a backup copy before beginning an intermediate or advanced extension.
