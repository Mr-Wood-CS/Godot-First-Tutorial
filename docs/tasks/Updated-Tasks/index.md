# Neon Drift Beginner Godot Tutorial Lessons

This 21 lesson sequence is based on the 8-video Godot 4.5 beginner playlist by Godot Dev Checkpoint. It has been tested with Godot 4.5.

https://www.youtube.com/playlist?list=PLVzjdZVCXNTz6ZCs_YcXTlXCZYzTOk-Q3

The source playlist introduces the Godot editor, scenes, nodes, GDScript, movement, input actions, reusable pickups, signals, UI buttons, win conditions and scene resets. This classroom version applies those ideas to **Neon Drift**, a space game in which the Player flies around and collects Sparks.

Each lesson is designed for a 45 minute classroom slot.

## Before You Start

This course builds **Neon Drift**. The Player flies up, down, left, and right to collect Sparks. There is no gravity, jumping, floor, or platform movement.

Complete the lessons in order using the same project. At the start of each practical task, open the scene named in the instructions. Save and test after every short section. Do not continue if the result does not match the **Test it** instruction.

Godot names are case-sensitive. For example, the group names `Player` and `player` are different.

When a code box says **complete script**, replace the existing script with the whole box. When it says **add**, keep the code you already have and insert only the new lines.

## Project Folders

Create these folders in the FileSystem panel to keep the project organised:

```text
res://
├── scenes
└── scripts
```

Save scene files in `scenes` and script files in `scripts`.
