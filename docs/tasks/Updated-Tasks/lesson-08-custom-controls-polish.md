# :material-tune: Lesson 8 - Custom Controls and Movement Polish

Source video: [Custom Controls! Add WASD & Input Actions Setup](https://www.youtube.com/watch?v=V7nb2uASbx8)

## Learning Intention

Improve player control by testing input actions and refining movement behaviour.

## Success Criteria

- I can test multiple control schemes.
- I can spot input mistakes.
- I can make movement stop correctly.
- I can comment code clearly.

## Keywords

| Keyword | Meaning |
|---|---|
| Control scheme | The set of inputs used to play a game. |
| Debug | Find and fix problems. |
| Comment | A note in code for humans. |
| Responsiveness | How quickly controls feel like they react. |


## Practical Tasks

1. Test A/D controls.
2. Test arrow key controls.
3. Check all four WASD and arrow-key directions are assigned in Input Map.
4. Check the Player stops when no key is pressed.
5. Add a short comment above the movement code.
6. Ask another student to playtest and give feedback.
