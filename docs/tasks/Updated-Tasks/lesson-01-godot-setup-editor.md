# :material-gamepad-variant: Lesson 1 - Godot Setup and Editor Tour

Source video: [Godot 4.5 Basics: Setup, Nodes, Scenes, & The Editor Explained!](https://www.youtube.com/watch?v=amGXbHVMPX0)

## Learning Intention

Learn what Godot is, create a new project and identify the main areas of the editor.

## Success Criteria

- I can create a Godot project.
- I can identify the Scene, FileSystem, Inspector and viewport panels.
- I can save a project in an organised folder.
- I can explain what a game engine does.

## Keywords

| Keyword | Meaning |
|---|---|
| Godot | A free game engine used to make 2D and 3D games. |
| Project | The folder containing all files for a game. |
| Editor | The main Godot workspace. |
| Viewport | The area where scenes are viewed and edited. |


## Practical Tasks

1. Create a project called `NeonDrift`.
2. Locate the Scene panel.
3. Locate the FileSystem panel.
4. Locate the Inspector.
5. Write one sentence explaining what each panel is for.
