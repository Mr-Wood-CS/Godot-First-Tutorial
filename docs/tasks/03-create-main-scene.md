# Task 3: Create `Main.tscn`

## Goal

Create the first scene the game will run.

## Key Words

| Word | Meaning |
| --- | --- |
| Scene | A saved collection of nodes. |
| Node | A building block in Godot. |
| Root node | The top node in a scene. |

## Do This

1. Click **2D Scene**.
2. Rename the root node to `Main`.
3. Save the scene in the `scenes` folder.
4. Name it `Main.tscn`.

## Check

The Scene dock should show a root node called `Main`, and the FileSystem should contain `scenes/Main.tscn`.
