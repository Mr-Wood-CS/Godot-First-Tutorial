# Task 4: Add A Background

## Goal

Add a dark background to the game window.

## Key Words

| Word | Meaning |
| --- | --- |
| CanvasLayer | A layer for screen items such as labels, buttons, and backgrounds. |
| ColorRect | A rectangle filled with one colour. |
| Inspector | The panel where you change settings for the selected node. |

## Do This

1. Right-click `Main`.
2. Add a `CanvasLayer`.
3. Right-click `CanvasLayer`.
4. Add a `ColorRect`.
5. Select the `ColorRect`.
6. In the Inspector, set its colour to very dark blue or black.
7. Set its anchors to **Full Rect**.

![Project background checkpoint](../assets/images/task-01-project.png)

## Check

The background should fill the whole game window.
