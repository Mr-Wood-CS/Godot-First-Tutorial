# Task 22: Place Hunters

## Goal

Put hunters into the arena.

## Key Words

| Word | Meaning |
| --- | --- |
| Pressure | The feeling that the player must react quickly. |
| Difficulty | How hard the game feels. |

## Do This

1. Open `scenes/Main.tscn`.
2. Drag `Hunter.tscn` into the scene.
3. Place it near an arena edge.
4. Add it to a group called `hunter`.
5. Duplicate it if the game feels too easy.
6. Do not place hunters on top of the player.

## Check

Press Play. A hunter should move toward the player.
