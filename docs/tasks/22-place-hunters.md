# Task 22: Place Hunters

## Goal

Put hunters into the arena.

## Do This

1. Open `scenes/Main.tscn`.
2. Drag `Hunter.tscn` into the scene.
3. Place it near an arena edge.
4. Add it to a group called `hunter`.
5. Duplicate it two times.
6. Put the three hunters on different arena edges.

## Check

Press Play. The hunters should move toward the player.
