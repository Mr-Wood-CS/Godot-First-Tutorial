# Task 20: Draw The Hunter

## Goal

Make the hunter visible and touchable.

## Key Words

| Word | Meaning |
| --- | --- |
| Collision shape | The invisible shape used for touching. |
| Arcade colour | A bright colour that stands out clearly. |

## Do This

1. Open `scenes/Hunter.tscn`.
2. Add a `Polygon2D`.
3. Make it red or pink.
4. Add a `CollisionShape2D`.
5. Set the shape to **New CircleShape2D**.
6. Set the radius to about `18`.

![Hunter checkpoint](../assets/images/task-05-hunter.png){ .media-frame }

## Check

The hunter should be visible and should have collision.
